# 1.18 泛化与兼容性边界

## 变化

- 设置页新增兼容性检查：公开工作资料启动 API、桌面 pin 能力、Android/Private 最低版本、当前 shell 环境中的解锁 Binder 方法签名。探测不修改资料；接口存在不代表 ROM 全部行为已验证。
- 升级后成功读取工作空间列表时迁移本应用的旧快捷方式。核对 userId、serial、父用户及资料类型；补齐类型、独立 URI 和工作徽标。旧身份不匹配、用户 ID 被复用或属于其它父用户时跳过，不猜测重定向。系统/其他应用创建的图标不在迁移范围。
- PRIVATE 卡片提供“私人空间启动策略”入口。用户主动配置重启后锁定，支持当前父用户而非硬编码 user0；使用临时写入权限、shell 读回值并清理本次权限。已有授权保持不变。界面明确“设置保存”和“ROM 实际执行”不同，需要重启验证。
- 标准 Android 工作资料 provisioning 不再要求先启动 Shizuku。实验多空间、应用管理及私人资料操作仍使用原执行模式。未删除或重建任何已有资料。

## 验证

clean assembleDebug test 通过，31 项测试（原24 + 策略权限事务4 + 旧身份迁移3）。包含 SDK不支持时不写入、失败后撤销权限、保留既有授权、父用户8、用户ID重用和跨父用户拒绝。

vivo V2545A / Android16：解锁 API 只读探测 AVAILABLE；旧 Private1 图标自动更新为 PRIVATE 类型与独立 URI，仍为原 user17 / serial1007。真实运行本版本 PrivateStartupPolicy 事务：临时授予、策略写入、shell读回2、撤销全部成功，权限未残留。工作资料 LauncherApps 路径继续保留。

Android12+ 可安装；Private功能要求Android15+且ROM支持。1.18完整实机验证范围仍为该vivo；小米此前版本已验证，不把模拟测试或接口探测称作所有ROM验收。vivo旧原生图标的资料选择缺陷仍未修补。当前发布为Dev包，与原版签名不同。
